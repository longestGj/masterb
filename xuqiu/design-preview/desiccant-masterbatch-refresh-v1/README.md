# Desiccant Masterbatch Category Refresh v1

Static design review for `/products/desiccant-masterbatch/`.

The current production page uses the generic `page-products` content template.
The proposal follows the section rhythm and media treatment of the Black
Masterbatch category while keeping desiccant-specific content and evidence.

## Preview

- Comparison: `compare.html`
- Proposed page: `index.html`
- Proposed desktop: `proposed-1440.png`
- Proposed mobile: `proposed-390.png`

## Metrics

- One H1.
- 10 direct page sections.
- Approximately 900 words in `main`.
- 11 images including shared Header and Footer.
- 1440px and 390px document widths match the viewport.

## Design direction

- Image-led category Hero with a clear review action.
- The current image set avoids the close-up product photos reused on product
  detail pages. It uses five distinct files from `img/`: factory-building,
  packaged bags, palletized shipment, workshop-equipment and
  factory-exterior-01.
- Seven-route contents index.
- Product-role, selection-input and DM2476G fact sections.
- Application routes matching the Black category.
- Dark evidence band separating "can solve" from "cannot replace".
- Controlled trial, documents, factory context, FAQ and final inquiry.
- Category copy follows the DM2476G product-page source for CaO chemistry,
  carrier, filler, moisture, dosage, applications, pre-drying and document
  boundaries. The category FAQ is a curated summary, not the full product-page
  FAQ set.

Production templates are intentionally not changed until the design preview is
approved.
