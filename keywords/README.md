## B 端采购修饰词

C12 专门补充产品词和采购角色、采购方式的组合，包括：

- 产品 + `factory`；
- 产品 + `supplier`；
- 产品 + `wholesale`；
- `bulk` + 产品；
- `OEM`、`private label` 和 `contract manufacturer`；
- `exporter`；
- 树脂或加工方式 + `supplier`；
- 中国工厂和产品级中国供应商组合。

这些词用于覆盖海外 B2B 采购搜索，不代表可以在页面中承诺工厂产能、现货、批发价、固定 MOQ、OEM 条件或中国出口能力。相关页面仍需业务方确认公司定位、交易条件和公开证据。

## 字段说明

| 字段 | 含义 |
|---|---|
| id | 关键词编号 |
| cluster | 所属主题集群 |
| keyword | 英文候选关键词 |
| intent | 搜索意图 |
| priority | P0、P1、P2 或 HOLD |
| page_type | 建议承接页面类型 |
| gate | 发布前需要满足的门槛 |

### 优先级

- `P0`：与首批黑色、白色、彩色母粒询盘和技术文件内容直接相关；
- `P1`：适合作为首批或第二版文章及支撑页面；
- `P2`：长尾、商业意图较弱或适合后续再验证；
- `HOLD`：当前证据不足、主体待确认或属于暂缓市场页面。

### 搜索意图

- `Informational`：解释概念、方法、选型或问题；
- `Commercial`：比较产品、应用、供应商或技术方案；
- `Transactional`：询价、样品、RFQ、文件申请等行动；
- `Navigational`：寻找特定品牌或供应商，当前词表中仅少量涉及。

### 发布门槛

| 代码 | 含义 |
|---|---|
| A | 通用内容门槛；仍需事实编辑和最终核验 |
| B | 需要具体产品牌号、当前文件或供应商书面确认 |
| C | 涉及 FDA、RoHS、食品接触或类似合规声明；只能按具体测试样品或牌号表达 |
| D | 涉及公开主体、公司能力、客户名称或文件归属，需要业务确认 |
| E | 产品证据不足，暂不应做正式产品页或适配承诺 |
| F | 国家或区域市场证据不足，暂不做市场落地页 |
| G | MOQ、价格、交期、付款或样品政策未确认，不能写固定承诺 |

`B/C`、`D/E` 等组合表示两个门槛同时存在。

## 使用规则

1. 一个页面选择一个主关键词，不要把 260 个词堆在同一页面；建页前先查看页面归并表。
2. 同一意图和同一主题的变体应合并到同一页面，例如 `masterbatch RFQ`、`masterbatch quotation` 和 `masterbatch sample request` 可以共同支持 RFQ 页面。
3. 产品、应用和文件页面必须使用具体牌号证据，不使用通用 TDS 数值或样品级报告代替整条产品线。
4. 文档相关词使用“申请、审核、邮件回复”表达，不使用“下载 TDS、立即获取证书”等表达。
5. `HOLD` 词可以继续做研究和内容储备，但不应直接创建空页面。
6. 发布前记录目标国家、搜索意图、搜索结果页类型、主关键词、搜索量和数据采集日期。
